# Fibonacci Series in C

## Description

This C program generates a Fibonacci-like series based on user input. It asks the user to enter the number of terms and the first two starting values, then prints the series by repeatedly adding the last two terms.

## How to Run

Compile the program using GCC:

```bash
gcc fibonacci.c -o fibonacci
```

Run the compiled program:

```bash
./fibonacci
```

On Windows, run:

```bash
fibonacci.exe
```
